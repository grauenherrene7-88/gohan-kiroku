# ごはん記録

食べたものを記録して、ビタミン・ミネラルまで含めた栄養を計算するアプリです。
スマホのブラウザで動く Web アプリ（PWA）で、データはその端末のブラウザの中にだけ保存されます。

## できること

- **市販品の登録**：パッケージ裏の成分表示を撮影して自動入力（端末内OCR・無料）／手入力／バーコードと紐づけ
- **バーコードで記録**：一度登録した商品は、次からバーコードを読むだけで記録できる
- **夕食（家の料理）の記録**
  - 「肉じゃが」「カレーライス」など約60品の標準料理から選ぶ（目安）
  - 材料とグラムを入れて「マイ料理」を作る（標準料理をもとにアレンジも可）
- **食品成分表の検索**：文部科学省の食品成分表 約2,500食品（「ごはん」「豚肉」などの普段の言い方でも検索可）
- **目標との比較**：年齢・性別・体重・活動量から「日本人の食事摂取基準（2025年版）」で目標値を自動計算し、不足（青）・適正（緑）・過剰（赤）を表示
- **履歴**：7/14/30日のグラフと平均
- **バックアップ**：JSONファイルに書き出し・読み込み

市販品はビタミン・ミネラルの表示がないことが多いため、空欄は「不明」として扱い、
合計に「※n品の値が不明（実際はもっと多い可能性）」と表示します（0として扱って誤解させないため）。

## PCで動かす（はじめての人向け）

1. Node.js が入っていることを確認します（PowerShell で `node -v` を実行してバージョンが出ればOK）。
2. このフォルダで PowerShell を開き、最初の1回だけ部品をインストールします。

   ```powershell
   npm install
   ```

3. アプリを起動します。

   ```powershell
   npm run dev
   ```

   「このシステムではスクリプトの実行が無効になっているため…」というエラーが出たら、
   `npm` の代わりに `npm.cmd` と打ってください（例: `npm.cmd run dev`）。

4. 表示された `http://localhost:5173` をブラウザ（Chrome か Edge）で開きます。
5. 止めるときは PowerShell で `Ctrl + C` を押します。

### 最初にやること

1. 下の「設定」タブでプロフィール（性別・年齢・身長・体重・活動量）を入れて保存
2. 「記録」タブの各食事の「＋ 追加」から記録

### PCで試すときの注意

- **成分表示の読み取り**：PCではカメラの代わりに画像ファイルを選べます（スマホで撮った写真をPCに送って試せます）。
  初回だけ日本語の文字データ（数MB）をインターネットから取得します。画像そのものはどこにも送信されません。
- **バーコード**：PCにWebカメラがあれば使えます。なければ「写真から読む」か数字の手入力で。
- データはブラウザごとに別です（Chrome と Edge では共有されません）。

## スマホで使うには（あとで）

カメラを使うには、アプリを https のアドレスで公開する必要があります（GitHub Pages など。無料）。
公開してスマホの Chrome で開き、メニューの「ホーム画面に追加」でアプリのように使えます。
公開しても記録データはスマホの中にだけ保存され、サーバーには送られません。

## 開発者向け

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー起動 |
| `npm test` | ユニットテスト（栄養計算・目標値・OCR解析・検索） |
| `npm run build` | 本番用ビルド（`dist/` に出力） |
| `npm run convert-foods` | 食品成分表Excel → `src/data/foods.json` を再生成 |

### 食品成分表データの更新

`src/data/foods.json` は、文部科学省「日本食品標準成分表（八訂）増補2023年」の
第2章データ（Excel）を `scripts/convert-mext.mjs` で変換したものです。
更新するときは [文部科学省のページ](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html) から
「第2章（データ）」の Excel をダウンロードして `data-src/mext-2023.xlsx` に置き、`npm run convert-foods` を実行します。
列の並びが変わった場合はスクリプトがエラーで知らせます。

### 構成

- `src/domain/` 栄養素の定義・計算・目標値（食事摂取基準の表）・検索
- `src/data/` 食品成分表データと標準料理プリセット
- `src/db/` 端末内データベース（Dexie / IndexedDB）とバックアップ
- `src/ocr/` 成分表示のOCR（tesseract.js）と文字列の解析
- `src/barcode/` バーコード読み取り（BarcodeDetector / ZXing）
- `src/ui/` 画面

## 出典・注意

- 食品成分: 文部科学省「日本食品標準成分表（八訂）増補2023年」（政府標準利用規約に基づき利用・加工）
- 目標値: 厚生労働省「日本人の食事摂取基準（2025年版）」。12歳以上が対象。妊娠・授乳中の付加量、持病による制限には対応していません。
- 標準料理の値は一般的なレシピからの目安です。このアプリは医療上の助言を行うものではありません。
